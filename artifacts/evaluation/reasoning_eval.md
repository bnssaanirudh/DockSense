# Reasoning-layer evaluation

Generated by `scripts/eval_reasoning.py` on physics-rendered clips with the
renderer's exact box geometry injected as perception.

## What this measures — and what it does not

| | |
|---|---|
| **Measures** | tracking, temporal features, the twelve behaviour detectors, deduplication |
| **Does not measure** | detection quality. YOLO-World correctly returns nothing on flat rectangles, so running it here would measure the renderer's photorealism, not the reasoning. Perception is validated separately on real industrial CCTV. |
| **Does not substitute for** | real footage of these behaviours. This is a logic benchmark, not a field result. |

**These thresholds were tuned against this set, so these numbers are NOT held out.**
Real recorded footage remains the held-out set and has not been collected.

Set: 5 positives, 4 hard negatives. Temporal IoU 0.3.

## Reading these honestly

**`no_tracking` collapses to zero.** Without persistent identity nothing temporal
accumulates, so no behaviour fires at all. This is the clearest evidence for the
central claim: the system detects *sequences*, not frames. Remove the sequence and
there is nothing left.

**`no_smoothing` and `no_event_graph` show no delta, and that is reported rather
than hidden.** Both have straightforward explanations, and neither is a win:

- *Smoothing* suppresses detector jitter. These clips are rendered with exact
  geometry and therefore have **zero** jitter, so there is nothing for smoothing to
  remove. Its value, if any, will only appear on real noisy detections — untested.
- *The event graph* feeds the recurrence component of the **risk score**. It does
  not change which events are detected, so event F1 is the wrong instrument for it.
  Measuring it needs risk-quality labels, which do not exist.

Reporting two flat rows is the point: a flag that changes nothing is evidence the
mechanism is not doing the work claimed, and that is worth knowing before a judge
asks.
